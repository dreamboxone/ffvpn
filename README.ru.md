## Требования

- OpenWrt 23.05, 24.10 или 25.12 на [поддерживаемой архитектуре](build/architectures.json).
- Для первой установки нужен SSH, доступ роутера к GitHub и аккаунт Mozilla. Установщик добавит LuCI и недостающие зависимости.
- Рекомендуется 32 МБ свободной флеш-памяти, 64 МБ временного пространства и не менее 256 МБ ОЗУ. Приложение и ядро занимают около 15–20 МБ. Зависимости и движок маршрутизации потребуют дополнительных ресурсов.
- Для маршрутизации LAN доступны автономный TUN, [Zirgozar](https://github.com/dreamboxone/zirgozar) и PassWall2. Для TUN нужен пакет `kmod-tun` для версии ядра роутера и зона межсетевого экрана с именем `lan`.

## Установка

Выполните команду на роутере через SSH.

```sh
wget -qO /tmp/ffvpn-install.sh https://raw.githubusercontent.com/dreamboxone/ffvpn/main/install.sh && sh /tmp/ffvpn-install.sh
```

Выберите **1 (Install / Repair)**. Установщик определит архитектуру, скачает подходящий выпуск и проверит подпись и хеши файлов. После установки откройте **LuCI → Services → ffvpn**. При первой установке главный переключатель выключен.

## Аккаунт Mozilla

Откройте раздел аккаунтов и выберите добавление пользователя. Введите почту и пароль Mozilla, затем завершите проверку. Можно добавить несколько аккаунтов, менять их приоритет, обновлять квоты и временно отключать аккаунты. При исчерпании квоты FFVPN может автоматически переключиться на другой аккаунт.

При прямом входе CAPTCHA отображается в форме. Введите символы с изображения и нажмите **Продолжить**. При повторном запросе показывается новое изображение.

### Вход через браузер

1. Откройте локальный адрес LuCI по HTTPS в Chrome или Edge. Перейдите на вкладку **Учётные записи**.
2. Нажмите **Скачать расширение FFVPN** и распакуйте ZIP. Включите режим разработчика на странице `chrome://extensions` или `edge://extensions`, затем выберите папку через **Загрузить распакованное расширение**. Установка нужна один раз для каждого профиля браузера.
3. В LuCI выберите **Добавить пользователя → Войти в Mozilla через браузер** и нажмите значок расширения в той же вкладке. Введите пароль и пройдите проверку в официальной вкладке Mozilla. Оставьте её открытой до завершения проверки, затем посмотрите результат в LuCI.

Браузеру нужен доступ к странице входа Mozilla.

### Резервное копирование и перенос аккаунтов

В разделе аккаунтов откройте резервное копирование и экспортируйте ZIP с аккаунтами и настройками ядра. Храните архив в тайне, поскольку в нём есть данные для входа. Для переноса выберите архив FFVPN или Arman VPN, проверьте список аккаунтов и подтвердите импорт. У аккаунтов с совпадающей почтой обновятся данные для входа. Текущие настройки роутера сохранятся.

## Подключение и маршрутизация

- **Отдельное устройство или приложение.** Включите главный переключатель и укажите в клиенте SOCKS5 с LAN-адресом роутера и портом `10810`. По умолчанию клиенты LAN подключаются без логина и пароля. Доступ из WAN закрыт, API управления доступен через loopback.
- **Вся сеть.** На главной странице в основных настройках выберите [Zirgozar](https://github.com/dreamboxone/zirgozar) или PassWall2 и примените настройки. Кнопка восстановления отменяет изменения FFVPN.
- **Автономный TUN.** Выберите этот режим в основных настройках. MTU интерфейса можно задать от 1280 до 9000 байт, по умолчанию 1500. LuCI показывает активный MTU после применения. Изменение MTU кратковременно перезапускает TUN. Режим обрабатывает интернет-трафик из LAN и сохраняет локальные маршруты, локальный DNS и трафик самого роутера.
- **Параметры соединения.** На вкладке серверов можно выбрать страну и измерить задержку. В основных настройках доступны HTTP/2, HTTP/3 и HTTP/1.1, а также выбор версии IP для соединений с прокси Mozilla. По умолчанию используются HTTP/2 и автоматический выбор с приоритетом IPv4.
- **Фрагментация TLS и часы.** Рядом с настройкой фрагментации TLS есть справка. Кнопка настройки часов устанавливает часовой пояс Тегерана и добавляет иранские серверы времени.
- **Ретрансляторы.** Личный и общий ретрансляторы включаются отдельно. Если личный не активен, общий может обработать управляющие запросы Guardian после HTTP 451. Трафик VPN идёт через туннель Mozilla.
- **Расширенные настройки.** На вкладке настроек можно задать вышестоящий SOCKS5-прокси, DNS ядра, правила раздельной маршрутизации и ограничения соединений. Проверьте настройки средствами тестирования DNS и маршрута.

В настройках соединения кнопка **Проверить ретранслятор** проверяет текущий адрес и показывает результаты этапов DNS и TLS. Ядро 1.0.18 добавляет резервные маршруты TLS при сбое соединения с ретранслятором, сохраняя режим **Требовать ECH**.

## Обновление и удаление

Версия приложения — `5.8.20-r1` (5.8.20, редакция 1). LuCI и обновлятор сравнивают редакции: `r2` новее `r1`. Для перехода со старого обновлятора без поддержки суффиксов редакций запустите установщик повторно и выберите **Установка / восстановление**.

- **С 1.0.2 на 1.0.3.** Повторите команду установки через SSH и выберите **2 (Update)**, чтобы обновить интерфейс и ядро вместе. В LuCI версии 1.0.2 также можно нажать **Обновить** в карточках **ffvpn** и **Ядро**. Затем обновите страницу LuCI.
- **Начиная с 1.0.3.** Для перехода на 1.0.4 обновите приложение и ядро вместе. На вкладке обновлений можно обновить оба компонента одновременно или проверить, обновить и переустановить каждый по отдельности. Для обновления только ядра нажмите **Проверить**, затем **Обновить** в карточке **Ядро**. У интерфейса и ядра независимые версии. Соединение может кратковременно прерваться.
- LuCI получает совместимое ядро из подписанного выпуска FFVPN. Обновление появляется после публикации соответствующего пакета FFVPN. При установке загружается полный архив и проверяются подпись и SHA-256.
- Для удаления установки, сделанной скриптом, снова выполните команду и выберите **3 (Remove)**. FFVPN отменит свои изменения маршрутизации и сохранит данные аккаунтов в `/etc/ffvpn/core`.

## Устранение неполадок

- **HTTP 406 при входе или продлении.** Проверьте версию ядра на вкладке обновлений. FFVPN 1.0.3 поставляется с ядром 1.0.17, в котором есть запасной путь для входа и продления. Если ошибка повторится, проверьте часы роутера и журнал.
- **HTTP 451 от Guardian.** Проверьте переключатели личного и общего ретрансляторов в основных настройках. Активный личный ретранслятор имеет приоритет.
- **Обновление не удалось.** Посмотрите подробности на вкладке обновлений, проверьте доступ к GitHub с роутера и свободное место. Незавершённую установку можно исправить через **1 (Install / Repair)** в установщике SSH.

## Пакеты OpenWrt

В [выпусках](https://github.com/dreamboxone/ffvpn/releases/latest) есть пакеты с LuCI для каждой поддерживаемой архитектуры. Для OpenWrt 23.05 и 24.10 нужен `ipk`, для 25.12 — `apk`. Архитектура должна совпадать с `DISTRIB_ARCH` в `/etc/openwrt_release`. Перед ручной установкой проверьте отдельную подпись `.sig` через usign и [публичный ключ FFVPN](files/usr/share/ffvpn/release.pub). Затем используйте `opkg install` с именем IPK или `apk add --allow-untrusted` с именем проверенного стороннего APK. Установленный пакет можно удалить через `opkg remove ffvpn` или `apk del ffvpn`.

## Ограничения и лицензии

FFVPN — неофициальный клиент. Доступность сервиса и квоты определяет Mozilla. Туннель поддерживает TCP-порты 80, 443, 8080 и 8443. UDP тоже ограничен по портам. Это может повлиять на звонки, игры и SSH.

Интерфейс и утилиты используют AGPL-3.0-or-later. Ядро основано на [Arman VPN](https://github.com/armanlife/arman-vpn-client), содержит точку входа для OpenWrt и сохраняет лицензию GPL-3.0. Тема и настройка часов взяты из [Zirgozar](https://github.com/dreamboxone/zirgozar). Лицензия Vazirmatn приложена к шрифту. Версии исходных проектов указаны в [UPSTREAM.json](UPSTREAM.json).
