## Возможности

- Установка вместе с LuCI, четыре языка, светлая и тёмная темы, тема маршрутизатора и значки вкладок.
- Несколько учётных записей Mozilla, порядок приоритета, квоты и автоматическое переключение.
- Немедленное применение настроек и переключатель включения без Save & Apply.
- Обнаружение Zirgozar и PassWall2; предупреждение перед изменениями маршрутизации и восстановление при выключении с сохранением последующих ручных правок.
- Отдельная проверка, обновление и переустановка приложения и ядра; путь к ядру и свободное место.
- Подписанные выпуски с полной загрузкой архива и проверкой SHA-256.
- Часовой пояс Тегерана и иранские серверы времени, как в Zirgozar.

## Установка

Целевые версии: OpenWrt 23.05, 24.10 и 25.12. Нужен LuCI; Zirgozar или PassWall2 требуется только для маршрутизации всей сети.

После первого опубликованного выпуска выполните через SSH:

```sh
wget -qO /tmp/ffvpn-install.sh https://raw.githubusercontent.com/dreamboxone/ffvpn/main/install.sh && sh /tmp/ffvpn-install.sh
```

## Установка, удаление и требования

Установщик автоматически определяет версию OpenWrt и архитектуру роутера и загружает нужные файлы. Целевые версии: 23.05, 24.10, 25.12; аппаратная проверка выполнена на 25.12.6. См. [architectures.json](build/architectures.json).

**Одна команда для установки и удаления:** команда выше открывает меню `1) Install`, `2) Update`, `3) Remove`. Для удаления повторите команду и выберите **3**. Данные аккаунтов сохраняются, изменения маршрутизации восстанавливаются.

**Флеш-память:** около 15–20 МБ для приложения и ядра, плюс отсутствующие зависимости. Рекомендуется минимум 32 МБ свободной флеш-памяти и 64 МБ временного пространства. Размер зависит от архитектуры.

**ОЗУ:** рекомендуемый минимум — 256 МБ общей памяти роутера; точный минимум для маломощных устройств не проверен. На тестовом роутере ядро занимало около 18 МБ резидентной памяти, наблюдаемый пик — около 42 МБ. Zirgozar или PassWall2 требует дополнительную память.

Отдельный SOCKS работает без движка маршрутизации: LAN-адрес роутера, порт `10810`, по умолчанию без логина и пароля, доступ только из LAN. API управления доступен лишь через loopback. Для всей сети выберите Zirgozar или PassWall2 в основных настройках и примените настройки; кнопка восстановления отменяет изменения.

Меню предлагает установку, обновление и удаление. Откройте LuCI → Services → ffvpn и добавьте учётную запись Mozilla. После установки маршрутизация выключена. При удалении данные учётных записей сохраняются.

## Ядро и ограничения

Ядро основано на [arman-vpn-client](https://github.com/armanlife/arman-vpn-client) с отдельной точкой входа для OpenWrt. Mozilla обновляет серверный сервис; совместимые сборки ядра распространяются через ffvpn. При обновлении загружается полный архив с проверкой подписи и хешей файлов.

Проект не связан с Mozilla и не одобрен ею. Квоты и доступность определяет Mozilla. TCP ограничен портами 80, 443, 8080 и 8443; UDP также имеет ограничения портов. Некоторые звонки, игры и SSH могут не работать. API управления слушает только loopback; SOCKS доступен из LAN и закрыт для WAN.

## Пакеты OpenWrt

В [релизе](https://github.com/dreamboxone/ffvpn/releases/latest) для каждой архитектуры есть единый пакет приложения и LuCI: `ipk` для 23.05/24.10, `apk` для 25.12. Архитектура должна совпадать с роутером. Установка: `opkg install /tmp/ffvpn_1.0.0-1_ARCH.ipk` или после проверки подписи `apk add --allow-untrusted /tmp/ffvpn-1.0.0-r1-ARCH.apk`. Сторонние APK не подписаны официальным репозиторием OpenWrt; приложены отдельные подписи usign `.sig` и SHA256SUMS. Однострочный установщик проверяет подписи автоматически. Удаление: `opkg remove ffvpn` или `apk del ffvpn`.
