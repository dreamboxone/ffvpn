## امکانات

- نصب همزمان برنامه و رابط LuCI؛ بدون نصب جداگانه رابط.
- چهار زبان، تم روشن و تیره و پیروی از تم روتر؛ برگه‌ها با آیکون.
- برگه کاربران با چند حساب موزیلا، ترتیب اولویت، سهمیه و جابه‌جایی خودکار حساب‌ها.
- کلید کشویی و اعمال فوری تنظیمات، بدون Save & Apply.
- شناسایی وضعیت زیرگذر و PassWall2؛ انتخاب خودکار یا دستی مسیریاب.
- هشدار پیش از تغییر مسیریاب؛ جلوگیری از حلقه ترافیک خود روتر؛ بازگردانی تنظیمات هنگام خاموش‌شدن و حفظ ویرایش‌های بعدی کاربر.
- برگه به‌روزرسانی برای بررسی و به‌روزرسانی جداگانه برنامه و هسته، نصب مجدد، مسیر هسته و فضای خالی.
- دریافت فایل کامل نسخه؛ بررسی امضای انتشار و SHA-256 پیش از نصب.
- تنظیم ساعت تهران و افزودن سرورهای زمان ایرانی، مطابق رفتار زیرگذر.

## نصب

هدف سازگاری، OpenWrt 23.05، 24.10 و 25.12 است. LuCI لازم است؛ زیرگذر یا PassWall2 فقط برای مسیریابی کل شبکه لازم است. حساب موزیلا را در پنل اضافه کنید.

در SSH روتر اجرا کنید:

</div>

```sh
wget -qO /tmp/ffvpn-install.sh https://raw.githubusercontent.com/dreamboxone/ffvpn/main/install.sh && sh /tmp/ffvpn-install.sh
```

## نصب، حذف و نیازمندی دستگاه

نصب کننده نسخه OpenWrt و معماری را از خود روتر تشخیص می دهد و فایل مناسب را دریافت می کند. OpenWrt 23.05، 24.10 و 25.12 هدف پشتیبانی هستند؛ آزمون سخت افزاری روی 25.12.6 انجام شده است. فهرست معماری ها در [architectures.json](build/architectures.json) است.

**نصب و حذف با یک دستور:** دستور بالا منوی `1) Install`، `2) Update` و `3) Remove` را باز می کند. برای حذف همان دستور را اجرا و گزینه **3** را انتخاب کنید. اطلاعات حساب نگه داشته می شود و تغییرات شبکه برنامه بازگردانده می شود.

**فلش:** حدود ۱۵ تا ۲۰ مگابایت برای خود برنامه و هسته؛ وابستگی های نصب نشده فضای بیشتری لازم دارند. حداقل ۳۲ مگابایت فضای خالی فلش و ۶۴ مگابایت فضای موقت آزاد پیشنهاد می شود. اندازه هسته به معماری بستگی دارد.

**رم:** حداقل پیشنهادی ۲۵۶ مگابایت رم کل دستگاه است؛ حداقل قطعی روی دستگاه های کم رم تایید نشده است. روی روتر آزمایش، مصرف مقیم هسته حدود ۱۸ مگابایت و اوج ثبت شده حدود ۴۲ مگابایت بود. اجرای همزمان زیرگذر یا PassWall2 به رم جداگانه نیاز دارد.

ساکس مستقل بدون نصب مسیریاب هم کار می کند: آدرس روتر، پورت `10810`، بدون نام کاربری و رمز به صورت پیش فرض، فقط از شبکه LAN. API مدیریت فقط روی loopback است. برای مسیریابی همه دستگاه ها، یکی از زیرگذر یا PassWall2 را در تنظیمات پایه انتخاب و دکمه اعمال تنظیمات را بزنید؛ دکمه بازگرداندن تنظیمات تغییرات را برمی گرداند.

<div dir="rtl">

منو گزینه‌های نصب، به‌روزرسانی و حذف دارد. سپس LuCI ← Services ← ffvpn را باز کنید. تنظیمات شبکه هنگام نصب تغییر نمی‌کنند؛ فعال‌سازی با نمایش هشدار انجام می‌شود. اطلاعات حساب هنگام حذف نگه داشته می‌شود.

## هسته و به‌روزرسانی

هسته از [arman-vpn-client](https://github.com/armanlife/arman-vpn-client) گرفته شده و ورودی مخصوص OpenWrt دارد. موزیلا سرویس سمت سرور را اداره می‌کند؛ سازنده این هسته نیست. تغییر سرویس موزیلا ممکن است به اصلاح هسته نیاز داشته باشد. نسخه سازگار هسته از انتشارهای ffvpn دریافت می‌شود.

به روزرسانی با دریافت فایل کامل نسخه انجام می شود. امضا با کلید ثابت و SHA-256 فایل ها پیش از جایگزینی بررسی می شود.

## محدودیت‌ها

این پروژه وابسته یا مورد تایید موزیلا نیست. سهمیه و دسترس‌پذیری حساب را موزیلا تعیین می‌کند. TCP فقط روی پورت‌های 80، 443، 8080 و 8443 پشتیبانی می‌شود؛ UDP نیز محدودیت پورت دارد. این محدودیت‌ها ممکن است تماس‌ها، بازی‌ها و SSH را تحت تاثیر قرار دهند. API مدیریت فقط روی loopback است؛ ساکس از LAN قابل دسترسی است و دسترسی WAN مسدود می شود.

## بسته های OpenWrt

در [ریلیز](https://github.com/dreamboxone/ffvpn/releases/latest)، برای هر معماری یک بسته یکپارچه برنامه و LuCI وجود دارد: `ipk` برای OpenWrt 23.05 و 24.10 و `apk` برای OpenWrt 25.12. نام معماری فایل باید با معماری روتر یکسان باشد.

```sh
opkg install /tmp/ffvpn_1.0.0-1_ARCH.ipk
# OpenWrt 25.12؛ پس از بررسی امضای فایل دانلود شده:
apk add --allow-untrusted /tmp/ffvpn-1.0.0-r1-ARCH.apk
```

بسته های شخص ثالث APK امضای مخزن رسمی OpenWrt را ندارند؛ فایل امضای جداگانه usign با پسوند `.sig` و `SHA256SUMS` همراه آن ها منتشر می شود. نصب کننده یک خطی امضا را خودکار بررسی می کند. برای حذف بسته: `opkg remove ffvpn` یا `apk del ffvpn`.
