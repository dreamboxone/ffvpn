## امکانات

- نصب همزمان برنامه و رابط LuCI؛ بدون نصب جداگانه رابط.
- چهار زبان، تم روشن و تیره و پیروی از تم روتر؛ برگه‌ها با آیکون.
- برگه کاربران با چند حساب موزیلا، ترتیب اولویت، سهمیه و جابه‌جایی خودکار حساب‌ها.
- کلید کشویی و اعمال فوری تنظیمات، بدون Save & Apply.
- شناسایی وضعیت زیرگذر و PassWall2؛ انتخاب خودکار یا دستی مسیریاب.
- هشدار پیش از تغییر مسیریاب؛ جلوگیری از حلقه ترافیک خود روتر؛ بازگردانی تنظیمات هنگام خاموش‌شدن و حفظ ویرایش‌های بعدی کاربر.
- برگه به‌روزرسانی برای بررسی و به‌روزرسانی جداگانه برنامه و هسته، نصب مجدد، مسیر هسته و فضای خالی.
- دریافت فقط فایل‌ها و بلوک‌های تغییرکرده؛ بررسی امضای انتشار و SHA-256 پیش از نصب.
- تنظیم ساعت تهران و افزودن سرورهای زمان ایرانی، مطابق رفتار زیرگذر.

## نصب

هدف سازگاری، OpenWrt 23.05، 24.10 و 25.12 است. آزمون واقعی فعلی روی Google WiFi با OpenWrt 25.12.6 انجام می‌شود؛ سازگاری سایر نسخه‌ها باید جداگانه تایید شود. LuCI و حداقل یکی از زیرگذر یا PassWall2 لازم است. حساب موزیلا را در پنل اضافه کنید.

پس از انتشار اولین نسخه، در SSH روتر اجرا کنید:

</div>

```sh
wget -qO /tmp/ffvpn-install.sh https://raw.githubusercontent.com/dreamboxone/ffvpn/main/install.sh && sh /tmp/ffvpn-install.sh
```

<div dir="rtl">

منو گزینه‌های نصب، به‌روزرسانی و حذف دارد. سپس LuCI ← Services ← ffvpn را باز کنید. تنظیمات شبکه هنگام نصب تغییر نمی‌کنند؛ فعال‌سازی با نمایش هشدار انجام می‌شود. اطلاعات حساب هنگام حذف نگه داشته می‌شود.

## هسته و به‌روزرسانی

هسته از [arman-vpn-client](https://github.com/armanlife/arman-vpn-client) گرفته شده و ورودی مخصوص OpenWrt دارد. موزیلا سرویس سمت سرور را اداره می‌کند؛ سازنده این هسته نیست. تغییر سرویس موزیلا ممکن است به اصلاح هسته نیاز داشته باشد. نسخه سازگار هسته از انتشارهای ffvpn دریافت می‌شود.

آپدیت تفاضلی تضمین نمی‌کند هر تغییر کوچک در سورس، دانلود بسیار کوچکی بسازد؛ اندازه دریافت به بلوک‌های تغییرکرده خروجی بستگی دارد. نصب اول به دریافت کامل نیاز دارد. امضاهای انتشار با کلید ثابت بررسی می‌شوند و بازسازی فایل‌ها پیش از جایگزینی انجام می‌شود.

## محدودیت‌ها

این پروژه وابسته یا مورد تایید موزیلا نیست. سهمیه و دسترس‌پذیری حساب را موزیلا تعیین می‌کند. TCP فقط روی پورت‌های 80، 443، 8080 و 8443 پشتیبانی می‌شود؛ UDP نیز محدودیت پورت دارد. این محدودیت‌ها ممکن است تماس‌ها، بازی‌ها و SSH را تحت تاثیر قرار دهند. دسترسی API و پراکسی هسته فقط روی loopback است؛ مدیریت از نشست معتبر LuCI انجام می‌شود.
